02 / What we actually ran

Inference, with a frozen model.

DeBERTa-v3 base zero-shot classifier
184,423,682 parameters · FP16 · 512 tokens

Every text is paired with twelve authored hypotheses. The model returns one entailment score per hypothesis. We retain the leading candidate, alternatives, review flags, and truncation details.

Weights are not updated

DSPy-style output

message → candidate act → signature skeleton

The signature is a proposed template. Its slots have not been extracted or executed. This run does not distill or train a new model.

1DeduplicateExact text hashes share a prediction.
2ScoreTwelve independent entailment pairs.
3ReviewWeak scores, narrow margins, and truncated messages.
4AttachProposed reusable signature templates.

03 / Why Modal

Rent GPU time.
Return completed shards.

Up to eight L4 GPU containers process independent shards in parallel.

Modal starts containers for the function calls and scales them down afterward. There is no permanent GPU server or always-on inference endpoint.

  • Only pending exact texts are sent for scoring.
  • Model and tokenizer files live in a private Modal Volume.
  • Each completed shard is saved atomically before import.
  • Ten-minute waves and an app watchdog bound the compute budget.

Operational choices

Small batches.
Durable checkpoints.

The first full wave hit memory limits on some L4 batches. The continuation uses 128 pairs per batch and 500-text shards.

Completed outputs are kept. Unfinished shards are retried from the remaining-text index.

04 / Measured pilots

Faster versus cheaper.

H10040.0 texts / second
L412.8 texts / second

68-message pilot; inference time excludes model loading. This sample is not a sustained full-corpus throughput guarantee.

L4 was about 18% cheaper per message after configured CPU and memory costs.

Both GPU pilots matched the local baseline on all 68 leading labels, review flags, and truncation outcomes. Maximum absolute score differences were below 0.004.

Parity checks the migration. It does not prove that the model’s classifications are correct.
